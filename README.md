# HACKS · 灵语 Memo

灵语 Memo 是一个收纳剧集语言、文化背景与个人感想的系列笔记本。首页是剧集集合，点进每一部剧可以阅读它自己的完整 Memo。

## 项目内容

- Words & Expressions：看剧时捡到的单词、俚语和口语表达
- Cultural References：理解笑点所需要的文化背景
- The line I want to keep：一条留下来的句子，以及它带来的联想
- My HACKS：关于 Deborah、Ava 和这部剧的个人感受

## 页面结构

- `index.html`：剧集笔记本集合首页
- `hacks.html`：HACKS 详情页
- `notebook.html`：新增剧集使用的可视化学习卡详情模板
- `notebooks.js`：首页的剧集卡片数据
- `style.css`：集合首页与详情页共用的视觉样式
- `app.js`：新增剧集、学习卡、搜索、编辑、删除和备份逻辑

## 当前核心流程

1. 在首页点击“留一页给下一部剧”的加号；
2. 填写剧名、简介和观看状态；
3. 自动生成一本新的剧集笔记本；
4. 在详情页添加表达、原句、解释和个人感想；
5. 学习卡可以编辑或删除；
6. 首页可以搜索笔记本，也可以导出和导入 JSON 备份。

## 从 AI 整理稿导入

详情页提供“从 AI 整理稿导入”入口。点击后可以复制内置提示词，发给正在使用的 AI，让它把自己的剧集笔记整理成固定 JSON；再把 JSON 粘贴回来，网站会预览分类好的学习卡，确认后一次性保存。

这个流程不读取原始 AI 对话，也不需要把 API Key 放进网站。AI 负责整理内容，灵语 Memo 负责校验格式、生成卡片和保存笔记。

新增内容目前保存在当前浏览器中，适合个人使用和 GitHub Demo 展示。它不会自动同步到其他设备，也不会写入线上公共数据库。

## 添加另一本剧集笔记本

1. 复制 `hacks.html`，例如命名为 `atlanta.html`；
2. 在复制出来的页面中替换标题和笔记内容；
3. 在 `notebooks.js` 的 `notebooks` 数组中增加一条记录，并把 `href` 指向新页面；
4. 如果需要，在 `style.css` 中给新剧集增加一个专属的颜色 class。

这个版本是静态网站：新增内容需要修改文件并重新发布。如果未来希望很多人在线登录、共同添加和编辑笔记，则需要再接入数据库和用户权限系统。

## 技术

这是一个不依赖框架的静态网站，使用：

- HTML
- CSS
- JavaScript

页面可以直接打开 `index.html` 查看，也可以部署到 GitHub Pages 或其他静态网站托管服务。

内容以个人学习笔记、语言观察和观后感为主。影视台词仅作为短例句使用，不构成字幕或剧本的完整转载。
